# Tamzen sources

These are the BDF files of Tamzen, unchanged, from the `bdf` directory of
<https://github.com/sunaku/tamzen-font> on its master branch (latest release: Tamzen-1.11.6),
fetched on October 2, 2026.
Tamzen derives from Tamsyn. `LICENSE` holds the terms of both.

`cargo xtask big-text` converts these files into `src/big_text/tamzen.rs`. Its check
mode compares the generated module with these files.
